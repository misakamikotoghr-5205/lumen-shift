# Existing work and our narrower difference

Checked 2026-11-05; exact commits and README/license SHA-256 values are in [source-versions.json](source-versions.json). Small sliding games, offline logic puzzles, undo and solver-assisted play already exist. We make no global novelty claim.

| Primary source                                                                                                                                         | Existing strengths                                                                                             | Lumen Shift's scope                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [2048](https://github.com/gabrielecirulli/2048/tree/478b6ec346e3787f589e4af751378d06ded4cbbc), MIT                                                     | Mature compact browser sliding game with touch input and stored best scores; README credits its antecedents.   | We do not merge numbered tiles or generate new tiles after moves. Independent bit shutters change a deterministic signal and explicit checkpoint readings; no upstream code, CSS or assets were copied.                                     |
| [Simon Tatham's Puzzles Android port](https://github.com/chrisboyle/sgtpuzzles/tree/d1e10eb57dd80af4999e698a9ab31f546e9a0b9d), MIT-style source notice | Large, mature portable puzzle collection, offline documentation, implicit saving and exchanging puzzle states. | We have only eight small handcrafted bit boards, no puzzle generator or native apps. We add a bounded orientation-space hint search and a visible per-row XOR explanation for this specific mechanic. Not a replacement for the collection. |

Both source licenses were read in full at the fixed commits. The Android port's notice explicitly excludes additional Google Play store graphics; those are not covered by the source notice and were not used. This project does not copy or vendor either project. Its own code, diagrams, level data and tone synthesis are independently authored with AI assistance under MIT. All runtime modules are local, with no third-party dependencies.

The concrete improvement here is an explainable signal trace, target checkpoints and a hint derived from the current board, packaged as a keyboard/touch browser game with validated action replays. These are implementation decisions, not proof that no other puzzle implements similar ideas.
